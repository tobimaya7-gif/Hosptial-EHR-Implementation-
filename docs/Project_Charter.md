# Project Purpose 
Sunset Community Hospital's goal is to replace its outdated electronic health record system with CareSync to improve patient care, streamline clinical workflows, and reduce duplicate documentation,
and enhance data accuracy. 

## Business Objective 
(why are we doing this project) 
- improve patient care by giving providers faster access to patient records
- reduce paperwork
- increase efficiency by streamlining appointments, charting, and billing
- improve communication between doctors, nurses, and admin
- ensure compliance with healthcare privacy and security regulations

## Project Scope 
(what the project will include and won't) 
Responsible for 
- Installing the CareSync EHR System
- Data migration
- User training
- Testing
- Go-Live support
- Post-Go-Live optimization

### Not my task 
- Construction or building renovations
- Hiring Doctors or nurses
- Remodeling hospital rooms 
- Medical equipment replacement
- Payroll system replacement
