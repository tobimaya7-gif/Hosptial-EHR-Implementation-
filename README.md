# Hosptial-EHR-Implementation-
Implementation Specialist: The hospital wants to replace its paper charts with Epic

#Overview 
This repository documents a simulated implementation of an Electronic Health Record (EHR) system at Sunrise Community Hospital.

The project demonstrates project management, stakeholder communication, risk management, workflow analysis, and implementation planning.

## Objectives

- Improve patient care
- Reduce paperwork
- Increase efficiency
- Ensure HIPAA compliance
- Train all hospital staff

## Tools Used

- Excel
- PowerPoint
- Microsoft Project (timeline)
